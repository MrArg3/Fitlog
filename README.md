# FitLog 🏋️ 

### Project
**FitLog — Workout Platform**
**FitLog** is a modern, responsive website and workout-planning web application built with **Next.js** and **Tailwind CSS**.Create a daily workout plan, save workouts for later, and track their workout progress.

#### ✨ Key Features

## 🛠️ Technologies Used   

- [x] **Next.js**            
- [x] **React**              
- [x] **TypeScript**         
- [x] **Tailwind CSS**       
- [x] **React Toastify**      
- [x] **Vercel**     

## 🎯 Project Highlights

* Dark UI
* Responsive grid, Navbar,Footer
* Daily & Saved workout Tab
* Live navbar counters
* Workout sorting/filter
* Toast notifications
* Loading states
* Empty states
* Custom 404 page
* Responsive navigation
* Persistent local data
* The project has been deployed on Vercel.

## 🏠 Workout Library

* Responsive workout card layout for all device.
* Loading animation when fetching.

### 📋 Workout Details

Each workout has a dedicated detail page.
* In workout details page have **Add to Today's Plan**, **Save for Later** button and **Toast notifications**
* 

### 📝 My Plan

The **My Plan** page allows users to manage their workouts.
* Today's Plan & Saved workouts tab
* Exercise, minutes & minutes count
* **View details**, **Mark as completed** & **Remove** Button
* Empty UI when no workouts are available

### 🔢 Dynamic Navbar

* Navbar displays **Plan** & **Saved** live counters and responsive.

### 🔍 Workout Sorting

Workouts can be sorted using the **Sort By** dropdown:
* Duration, Calories & Rating

The selected sorting option dynamically updates the current workout list.

### 💾 Persistent Workout Data

Workout plan and saved workout information can be stored using **localStorage**.

### 📱 Responsive Design

FitLog is designed to work across:
* 📱 Mobile, 📲 Tablet & 💻 Desktop
